# Channel Lead Analytics

东风日产渠道线索分析静态网站。仓库只包含网站本体，不包含默认业务数据、Excel 模板或上传文件。

## 在线站点

- GitHub Pages：`https://django604.github.io/Channel_Lead_Analytics/`
- Cloudflare Pages：`https://django604-channel-lead-analytics.pages.dev/`

## 数据说明

- 首次打开为空数据状态，需要点击“上传 Excel”加载数据。
- 支持 `.xlsx` / `.xls`、拖拽上传、多文件同级数据合并和按表头名称识别字段。
- NEV 固定统计口径会排除车型名称中包含“探陆”的全部记录；上传反馈会同时显示源数据行数、参与统计行数和排除行数。ICE 独立统计，不继承 NEV 的车型排除规则。
- 区域分析的大区排名按车型堆积展示，并在柱形末端保留大区合计；所有非零分段数字固定显示在对应色块内，并按分段宽度自适应字号，未标注车型的有效数据单列为“未标注车型”。
- 图表生成的指标漏斗仅使用数量指标绘制漏斗阶段；所选到店率、试驾率、锁单率等转化效率放大显示在漏斗右侧，并与对应的到店、有效试驾和锁单阶段对齐。
- 图表生成支持 Excel 式瀑布图：按分类依次累计第一项数量指标，用蓝色台阶柱与连接线展示承接关系，负数项使用红色向下展示。
- 图表生成通过“展示分类”多选实际展示项：年月或按月汇总时可勾选指定月份，其他维度可选择对应渠道、大区等分类；支持搜索、显示全部与清空选择，查看数据及合计同步按所选分类计算。切换维度或日期汇总粒度时恢复全部分类。
- 渠道、大区或小区作为 X/Y 轴分类时，只保留对应“展示…”多选，原同维度画布筛选自动合并到此入口；其他维度筛选继续保留。未选择分类维度时隐藏展示项和排序，散点图与指标漏斗隐藏无效排序，饼图/环形图图例只展示分类、不再另行切换。顶部筛选影响全部画布，画布内设置只影响当前图表。
- 渠道、大区、小区、车型等非时间维度支持独立“展示月份”多选；柱形、折线、面积及组合图可从“合并汇总”切换为“按月拆分”，分类轴保持原维度，每月生成独立系列，多指标堆积在各月内分别计算。查看数据同步显示“月份 × 指标”列及各月合计，可转置；转化率使用对应源数据重算，缺月留空，未标注月份单列。优先读取年月字段，缺失时从日期推导；年月或日期本身作为分类轴时不重复增加月份筛选。其他图表可通过月份多选查看指定单月或合并范围。
- 成本计算器默认统计除探陆外全车系，只展示 R3、R4、R5、R6、R8车巡展、R8商超、R10、R11 八个成本渠道；支持 CPL、CPQL、CPT、CPTD、CPO、CPS 六种费用/实绩口径、多个时间范围横向对比，以及从 Excel 直接粘贴“渠道 + 费用”两列数据。
- 车型分析支持选择主车型自身或其他一个/多个车型进行双周期对比；环比仅在对比范围存在数据且基期指标不为 0 时计算，对比范围无记录时显示“对比期无数据”，基期为 0 时显示“环比 --”。加入有效对比后，日趋势图按区间相对位置叠加当前与对比两条线；日期范围不同时，X 轴用双行标签分别显示两边的真实日期。
- Excel 由浏览器本地解析，文件不会上传到 GitHub 或 Cloudflare。
- 浏览器会将最近一次成功解析的数据保存在当前设备的 IndexedDB；更换设备或清理站点数据后需要重新上传。

## NEV 与 ICE 板块

- NEV / ICE 切换按钮保留高斯背景模糊，选中时使用深红色半透明底与白色文字，未选中使用浅色玻璃底；按钮旁的板块状态说明已移除。页面 CSS 引用带版本号，减少旧样式缓存影响。

- 首页通过“NEV 新能源 / ICE 燃油车”切换；上传弹窗左右分为两套完整区域，每套有独立的文件选择、拖拽、文件列表、上传按钮及反馈，ICE 月份设置放在右侧。两边可分别或同时上传，单边失败不会影响另一边；上传其他板块不会切换当前主页。切换时分别保留当前页面、筛选、漏斗、图表画布、店均设置及费用输入；“恢复默认”只处理当前板块。刷新后两套数据仍分别读取本地缓存，原 NEV 缓存兼容保留；页面设置和手填费用仍仅保留在当前页面会话中。
- ICE 识别“车系名称 / 专营店名称 / 集团名称”等表头，线索总量对应线索指标、到店量对应到店指标、订单总量对应大定指标、成交量对应锁单指标，界面显示 ICE 名称。未提供试驾时不生成试驾阶段、转化率或成本入口。
- ICE 车型按照知识库的“ICE车型匹配”表，由数据源命名转换为统计命名；未匹配名称保留参与统计，上传反馈显示未匹配数量。规则随网站内置，无须每次上传知识库。
- ICE 仅展示 7 个指定车型：十五代轩逸、轩逸经典、第14代轩逸、P32S MC Refresh逍客、P32R-e 奇骏经典、P42R 探陆、B12L 骐达。首页车型卡片、车型筛选与对比、车型排名、区域车型堆积、成本车型选择及图表车型明细统一使用此名单，按数据中存在的车型提供入口。其他车型与未标注车型仍参与“全部车型”的总体、月份、渠道、大区和成本汇总，原始数据及缓存完整保留；指定车型堆积的分段只展示名单内车型，合计仍显示全车型总量。图表使用全部车型分类时，查看数据的合计及各月合计包含隐藏车型，并附口径说明；明确勾选车型子集时按所选车型汇总。NEV 展示规则保持原有逻辑。
- 车型总览支持多行等宽卡片，四列和双列换行后继续避开左侧阶段选择列；屏幕宽度不超过 920 px 时改为单列，避免车型名、漏斗及底部指标挤入窄列。
- ICE 渠道按照“渠道匹配公式”工作表的 ICE 公式优先级匹配，并使用修正后的统计命名：大项目含总部员工号、N6女团、天籁福利社、ysy，或媒体含总部自媒体，归为 R11总部自媒体；渠道含新媒体或 R6，且大项目含 R5、经销商或 D直播，归为 R10经销商新媒体；其他新媒体 / R6 归为 R6总部新媒体；其余保留原渠道。判断不区分英文字母大小写，仅同时提供渠道、大项目和媒体列时执行。读取已有 ICE 缓存时，旧 R6-1 / R6-2 / R6-3 名称分别归入 R6 / R10 / R11，同一渠道的新旧名称合并筛选和汇总，原始行与指标保留；成本计算器按 R6、R10、R11 独立录入费用，粘贴费用兼容旧编号。
- ICE 优先使用 Excel 内的日期 / 年月。两列都不存在时，可在上传区指定月份，或从各文件名（例如“西南区-2026-09.xlsx”）识别月份；无法识别时提示补充月份，不伪造日级日期。月度数据支持顶部月份筛选、车型月趋势、专店月度对比、成本月份对比及图表按月展示。
- “总交车量”是重复的门店汇总值，当前不作为逐行累加指标；因此仅含此列的 ICE 文件不展示交车量或 CPS。提供明细“交车量”列时才启用对应指标。

## 验证

- `npm run verify:chart-categories`：分类选择及分月图表回归。
- `npm run verify:business-sectors`：NEV / ICE 上传、清洗、缓存兼容和状态隔离回归，使用合成数据，无须浏览器。
- `node scripts/verify-business-sectors.js "ICE数据.xlsx" "知识库.xlsx"`：额外只读核对真实文件的车型转换及指标合计，不写入源 Excel。
- `npm run verify:model-focus`：包括 NEV / ICE 上传与切换在内的浏览器交互回归，需要可启动的 Microsoft Edge。

## 发布方式

推送 `main` 分支后，两个独立 GitHub Actions 工作流分别部署 GitHub Pages 与 Cloudflare Pages。项目不包含定时取数或自动更新任务。

Cloudflare 工作流会自动创建 Pages 项目；新仓库只需配置 `CLOUDFLARE_ACCOUNT_ID` 和 `CLOUDFLARE_API_TOKEN` 两个 Actions Secret。
